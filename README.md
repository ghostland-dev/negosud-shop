# Negosud Shop

Online wine shop front-end built with Vue 3.

## Features

- Vue Router and Vuex store
- Stripe payments
- Product carousel and cart

## Tech Stack

- Vue.js
- Vuex
- Stripe

## Getting Started

```bash
git clone https://github.com/ghostland-dev/negosud-shop.git
cd negosud-shop
npm install
npm run serve
```

Other scripts:

- `npm run build`: vue-cli-service build
